{%- comment -%} This layout overrides the stub template jekyll-redirect-from would otherwise generate. The plugin installs its own default only when the site has no layout named `redirect` — see generator.rb — so adding this file is the whole mechanism, and it is how the plugin is meant to be restyled. It matters because the default template ships with no styling and no `color-scheme`, so a reader whose redirect has not fired yet gets an unstyled white page that ignores their theme choice, on a site whose every other page follows both. A part that moves emits one of these at its old permalink, so this is the page a reader is guaranteed to see at least once after any URL change. SELF-CONTAINED ON PURPOSE. No stylesheet link and no webfont. A redirect stub is what is on screen for the moment before the browser navigates away, and it is the entire page for anyone whose JavaScript is blocked; pulling a font over the network to announce a URL change would make the redirect the slowest part of the click. So the colours are the site canvas and accent restated inline, and the dark half comes from the media query alone — which means a reader who chose Dark gets a dark stub even though this document never runs the preference module. Keep those literals in step with theme.css's `--c-bg-ch` and `--c-accent-ch`. {%- endcomment -%} Redirecting…
