The 16 LLM pages write their `` by hand and include this file after their own `styles.css` link, so unlike guide-head.html this one cannot guarantee it runs before the first stylesheet request — it can only guarantee it runs before the first PAINT, which is the half that matters: a pending stylesheet blocks paint, so the boot script's writes to are already in place when the first frame is composited. No flash either way. The boot script is included here for that reason: the guarantee belongs to the file, not to a convention about which includes precede which. `color-scheme` and the two `theme-color` metas with their `prefers-color-scheme` media variants are here for the same reason — they are the no-JavaScript fallback, and a page that has the boot script has JS, so a page WITHOUT it is the one they are for. {%- endcomment -%} {% include theme-boot.html %}
