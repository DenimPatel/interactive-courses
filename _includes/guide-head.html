{%- comment -%} Order matters twice over, here. 1. The boot script goes BEFORE any stylesheet, because that is the only place it can do its job: a deferred external file runs after the browser has already decided what colour the first frame is, and a reader who chose Dark must never see a light one. It writes `data-theme` plus the five `--pref-*` custom properties and the `theme-color` metas onto while the parser is still in , so the very first paint is already correct. 2. `color-scheme` is declared so that a visitor whose JavaScript never runs still gets a scrollbar, a caret and native form controls that match the operating system rather than contradicting it. The boot script overrides it inline the moment it runs, because an explicit choice outranks the query. 3. theme.css then chrome.css come AFTER styles.css and guide.css. theme.css is the token layer and re-points the `--color-*` / `--radius-*` / `--shadow-*` / `--space-*` aliases at the new palette; at equal specificity later wins, and it has to win. chrome.css is the chrome this file's siblings pull in: the top bar, the skip link, the theme toggle and the settings panel.
