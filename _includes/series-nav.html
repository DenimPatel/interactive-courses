{%- comment -%} Series part picker. Usage: {% include series-nav.html series=site.data.series.multi_view_geometry %} Renders the part list, then (via the script below) moves it into the left sidebar (#site-nav, from site-nav.html) so it lives in the same collapsible pane as the rest of the site nav rather than as a second bar above the content. Left in its original DOM position — right after site-nav — it is still a fully usable pill row, which is what a no-JS visitor gets. When the series declares an `acts:` list, the pills are grouped under act labels (presentational only: `num` is still the single source of part numbers, and series-prevnext.html still walks parts + appendix in flat order). {%- endcomment -%} {%- assign current_part = nil -%} {%- for part in include.series.parts -%} {%- if page.url == part.permalink or page.permalink == part.permalink -%} {%- assign current_part = part -%} {%- endif -%} {%- endfor -%} {%- for extra in include.series.appendix -%} {%- if page.url == extra.permalink or page.permalink == extra.permalink -%} {%- assign current_part = extra -%} {%- endif -%} {%- endfor -%}
Contents {%- if include.series.acts -%} {%- for act in include.series.acts -%} {{ act.label }} {%- for part in include.series.parts -%} {%- if part.act == act.id -%} {{ part.short }}{{ part.title }} {%- endif -%} {%- endfor -%} {%- endfor -%} {%- for extra in include.series.appendix -%} {{ extra.short }}{{ extra.title }} {%- endfor -%} {%- else -%} {%- for part in include.series.parts %} {{ part.short }}{{ part.title }} {%- endfor %} {%- for extra in include.series.appendix %} {{ extra.short }}{{ extra.title }} {%- endfor %} {%- endif %}
